# Hackathon memo B: house-scale generated worlds landscape (2026-09-03)
- Family A (video/pano diffusion -> 3DGS): relative scale, extent = trajectory. HunyuanWorld 1.0 (layered mesh, Tencent licence excl EU/UK/KR), HY-World 2.0 (3DGS+mesh+ptcloud, Isaac import), Voyager (60 GB VRAM, too big), Matrix-3D (MIT, ~1 h/scene), FlashWorld (Apache, 16.6 s, 30 GB), Lyra (Apache), Gen3C (video only), SEVA (non-commercial), WonderWorld. Genie 3 no export.
- Family B (LLM floor plan -> mesh shell -> appearance): METRIC by construction. WorldMesh (ECCV 2026, MIT core): text -> floor plan -> extruded walls with doors -> mesh-conditioned diffusion -> 3DGS; 4-12 rooms, 80-256 m2, single A5000, 0.8-1.5 h/scene (API images) or 2.2-6.6 h local; schema units=meters, z_up, wall 0.15, ceiling 2.8, graph_connected validator; single-story, rectangular rooms. https://github.com/mschneider456/worldmesh
- Layout-first: ProcTHOR-10K: ~12,000 houses as GLB + semantic JSON at HF hssd/ai2thor-hab (same channel as HSSD-200), Apache, $0. Infinigen Indoors: best truth, USDC-only export, 8-13 min CPU per ROOM, issue #352 unreachable rooms. Holodeck ~$1/house + 3 min. HomeWorld (5K furnished homes promised), MANSION (multi-floor) = 2026 watch-list.
- Chain-of-rooms: PanoWorld (floorplan shell + 3DGS cache, no code, 64 H200s) and WorldComposer (pano -> Marble -> 3DGS + collision mesh, rooms registered by LightGlue + point-to-plane ICP, USD export; scale from camera height alpha = h / median ground depth; no code; seams at junctions). Lesson: chain a SHELL, not generation. Marble pano:depth_to_rgb = render depth pano from our shell at each node -> Marble paints -> world. Pano docs sanction 3D-software-rendered 2:1 panos.
- Real-to-sim video: VGGT/pi3/MASt3R scale-free; metric: MapAnything, Depth Anything 3 metric variants, MoGe-2, AMB3R. Mesh: DN-Splatter with sensor depth Chamfer 2.2 cm F 0.94; without depth F@5cm 0.34-0.43. EmbodiedSplat: 30 min iPhone capture + 1-2 h -> Habitat; mirrors/glass unrepresentable.
- Ranking for 1,000 houses: A ProcTHOR GLBs ($0), B WorldMesh layout stage ($0, truth shell), C shell -> Marble depth_to_rgb (~$1.28, appearance), D video capture (doesn't scale), E Holodeck (skip).
- Hackathon demo: Marble API text->world + collider GLB + Tripo objects + our 44k-ray panel.
- Unresolved: WorldMesh shell as standalone GLB (combine_glb.py unread); ai2thor-hab licence; Infinigen per-house cost.
