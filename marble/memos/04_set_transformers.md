# Memo 4: set transformers over partial 3-D maps, query-position prediction
- Query decoding pattern: query = PE(where) + learned "what" token, cross-attends scene latents. I-JEPA predictor narrow/shallow (384-d, 6-12 layers). Perceiver IO decodes per output point O(output). SRT: ~320 latents x 768, query ray Fourier PE 15 octaves (180-d); 2 decoder layers optimal, 2-layer MLP head 128; 8192 queries/step.
- 3-D PE: 3DETR Fourier XYZ 62.7 AP25 vs sinusoid 55.8 vs none 31.3; non-parametric queries = FPS positions + Fourier + MLP. V-JEPA 2 uses 3D-RoPE.
- GEOMETRIC SHORTCUT: Point-MAE — mask tokens carrying positions in the ENCODER leak the answer: better recon loss, worse features (92.14 -> 93.19 when moved to decoder). Random 60-80% mask beat block for Point-MAE. Sonata: SSL collapses to height/normal cues (21.8 vs 77.6 mIoU); fixes: drop U-Net decoder (20.7->60.4), up-casting (65.3), jitter sigma=0.01 on masked points (68.2), progressive mask size 10->40 cm and ratio 30->70% (~70), final 72.5.
- I-JEPA masking: 4 target blocks scale (0.15,0.2), context (0.85,1.0) with overlap removed; multi-block 54.2 vs random 17.6; feature-space 66.9 vs pixel 40.7. 3D-JEPA reproduces: FPS centers + KNN blocks; context-aware decoder cross-attends context at every layer, 2 layers. Point-JEPA: greedy NN sequencer to define blocks; 7.5 h on one A5500.
- Frozen target beats EMA for us: MaskFeat frozen DINO targets 84.2 (supervised features underperform); V-JEPA 2-AC freezes encoder, trains 300M predictor with L1 + 2-step rollout, no anti-collapse needed; DITR distills frozen DINOv2 per-point with cosine loss (+2.4 ScanNet mIoU, +7.1 ScanNet200).
- Joint occupancy+feature at query: POP-3D (two heads). Imbalance: Occupancy-MAE focal loss + range-aware mask ratios (90/70/50%); Lovasz-softmax; SelfOcc predicts SDF instead of binary.
- Scale: 3DETR 2048 tokens full attention on one V100; V-JEPA 2 dense 4096 tokens, cooldown 36,864. 10k tokens x 50M params fine on a 5090 with FlashAttention. Data is the constraint.
- Uncertainty: deterministic L2 predictors blur; Plan2Explore latent ensemble disagreement = expected surprise (best precedent for "where next"). Var-JEPA / MoP-JEPA 2026 preprints UNVERIFIED.
- Design: freeze DINO target, cosine loss; never let query positions into the encoder; jitter cell centres; progressive curriculum; block masking via spatial sequencer; query head Fourier XYZ + learned token, 2 cross-attn layers; occupancy focal/SDF + feature; small predictor ensemble for disagreement.
